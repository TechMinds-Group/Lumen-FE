# Assets

Esta pasta contém os arquivos de dados da aplicação:

- **meta.json**: Metadados do projeto (eixos, labels de tags, dimensões e campos)
- **thinkers.json**: Lista completa de pensadores políticos organizados por eras históricas

## Estrutura

Os arquivos JSON seguem o padrão:
- **Keys**: Em inglês (padrão internacional para desenvolvimento)
- **Values**: Em português (conteúdo exibido ao usuário)

## Versão 2.0 - Dimensões Expandidas

### 7 Eixos Analíticos

1. **Liberdade vs. Autoridade** - Orientação política fundamental
2. **Estado vs. Mercado (+ Comunidade)** - Organização econômica
3. **Tradição vs. Ruptura** - Atitude perante mudança
4. **Individual vs. Coletivo** - Foco ontológico
5. **Método** - Abordagem epistemológica (6 categorias)
6. **Antropologia Filosófica** - Visão da natureza humana (otimista/pessimista)
7. **Escopo de Aplicação** - Alcance geográfico-cultural (universal/particular)

### Tags Disponíveis (20 valores)

**Políticas:** freedom, authority, state, market, community  
**Temporais:** tradition, rupture  
**Ontológicas:** individual, collective  
**Metodológicas:** rational, empirical, dialectic, historical, idealist, realist  
**Antropológicas:** optimistic, pessimistic  
**Geográficas:** universalist, particularist

### Paleta de Cores

- **Tradição**: Azul/céu (estabilidade)
- **Ruptura**: Vermelho intenso (transformação)
- **Método**: Bordas com peso médio (destaque visual)
- **Antropologia**: Amarelo (otimista) / Cinza (pessimista)
- **Escopo**: Azul forte (universal) / Laranja (particular)
