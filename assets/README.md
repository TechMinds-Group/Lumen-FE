# Assets

Esta pasta contém os arquivos de dados da aplicação:

- **meta.json**: Metadados do projeto (eixos, labels de tags, dimensões e campos)
- **thinkers.json**: Lista completa de pensadores políticos organizados por eras históricas

## Estrutura

Os arquivos JSON seguem o padrão:
- **Keys**: Em inglês (padrão internacional para desenvolvimento)
- **Values**: Em português (conteúdo exibido ao usuário)
